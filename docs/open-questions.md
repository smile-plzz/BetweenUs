# Open Questions

These are intentionally unresolved. They are **not blockers to beginning the core validation build** unless marked pre-production. When evidence resolves one, record the decision in `09-decisions/decision-log.md`.

## Product / positioning
1. Is “digital home for two” best as external positioning or mainly the internal metaphor?
2. Which initial audience has the strongest pull: dating, long-distance, cohabiting, newly married, or another segment?
3. Does **BetweenUs** survive trademark/domain/app-store research?

## First-use / adoption
4. What delivers value before the shared collection has history?
5. What convinces Partner B to install after Partner A invites them?
6. Should the first joint action be a capture, reaction, Question Card or guided decision?

## Capture / memory
7. Which external share sources dominate the first pilot?
8. Is an optional note enough to preserve “why I saved this” context?
9. What categorization error rate becomes trust-damaging?
10. How should screenshots/non-link content be handled without excessive AI/privacy dependency?
11. What is the minimum useful reaction vocabulary?

## Home / presence
12. How literal should the room metaphor become visually?
13. What should Home contain after hundreds of objects accumulate?
14. Which presence signals create closeness rather than pressure?
15. Should playful traces persist or disappear after delivery?

## Shared Question Cards
16. Should responses reveal immediately or, for some prompt types, only after both answer?
17. Can the sender answer their own card before/after sending?
18. Which response formats belong in V1: text, binary, slider, multiselect, image/link?
19. When does an answered card become durable memory versus fade away?
20. How long should unresolved cards remain prominent without creating inbox debt?

## Intimacy & Desire
21. Is intimacy best represented as a view/category, sensitivity metadata, presentation mode, or combination?
22. How should couple-controlled sexual tone/intensity be configured without making desire feel like a settings panel?
23. What exact controls prevent accidental explicit notification/widget exposure?
24. How should changing preferences/boundaries be represented without becoming clinical?
25. Which explicit prompt categories are useful versus gimmicky or pressuring?

## Spiritual Intimacy / Faith Together
26. Is “Faith Together” the right user-facing label while “Spiritual Intimacy” remains architectural language?
27. Should the first implementation be explicitly Islam-first or use a configurable faith layer from day one?
28. What verified Qur'an/hadith corpus/API/licensing approach should provide source integrity?
29. Should prayer invitations integrate calculated/local prayer times in the first faith prototype or begin as manual invitations?
30. Which shared Ramadan/Jumu'ah/dua/charity experiences are genuinely relationship-enhancing rather than gamified worship?
31. How should madhhab/practice differences and varying religiosity be represented respectfully?

## Decision support / intelligence
32. Which first decision domain has strongest repeat value: movies, food/places or activities?
33. What candidate count feels helpful rather than restrictive?
34. When should external discovery appear relative to saved items?
35. How should strong disagreement be handled?
36. Which signals may intelligence learn automatically versus only from explicit shared input?

## Finance / travel
37. Is rough per-date budget sufficient or do couples want shared experience budgets?
38. Can purpose funds work without bank connections?
39. Should BetweenUs hand off to Wayfare, embed a view, or share a model later?

## Data lifecycle & safety — **pre-production decisions required**
40. What happens to shared content when a couple unpairs?
41. Can both independently export a copy?
42. How are deletion rights handled for jointly enriched content?
43. What immediately revokes sensitive presence/location access?
44. What happens to explicit/intimate content on unpairing, export and backup?
45. What account/device recovery model protects sensitive couple data?

## Business model
46. Subscription, one-time purchase, freemium or free during validation?
47. Which features can ethically support monetization without selling sensitive data or exploiting relationship anxiety?

## Validation
48. What behavioral threshold moves the product beyond founder testing?
49. How many external couples are enough for the first qualitative round?
50. What evidence would cause the wedge to be abandoned or radically repositioned?
51. What evidence shows Question Cards create a genuine second habit rather than novelty?
52. What evidence justifies moving Intimacy/Faith from vision into deeper implementation?
