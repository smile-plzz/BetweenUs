# Roadmap

The roadmap is evidence-gated, not date-gated.

## Phase 0 — Product definition **(current)**

Goal: establish a coherent product thesis and prevent premature feature sprawl.

Deliverables:
- vision/problem/principles;
- JTBD and psychology framing;
- PRD;
- feature map;
- trust boundaries;
- technical direction;
- validation plan;
- open questions/decision log.

Exit: team can explain the product without relying on a giant feature list.

## Phase 1 — Capture prototype

Goal: prove that saving is effortless enough to compete with “just send it in chat.”

Build:
- pairing;
- shared backend;
- URL/manual capture;
- mobile-first shared collection;
- basic metadata;
- reactions;
- basic filters;
- instrumentation.

Exit: both members repeatedly capture real content.

## Phase 2 — Memory activation

Goal: prove that saved content becomes useful later.

Build:
- resurfacing;
- search;
- simple intent modes (Watch/Eat/Do);
- finite ranked candidates;
- completion + ratings;
- return experience.

Exit: saved items influence real decisions.

## Phase 3 — Shared presence experiments

Goal: determine whether the “digital home” feeling creates differentiated emotional value.

Experiments:
- “leave something for you”;
- lightweight tap/kiss/gesture;
- shared-room presence;
- subtle traces/changes;
- discreet notification controls.

Do not build full messaging.

Exit: presence creates desired closeness without pressure/noise.

## Phase 4 — Contextual intelligence

Goal: improve decisions without creating an AI persona.

Add selectively:
- semantic retrieval;
- richer preference learning;
- explainable external discovery;
- time/distance/rough-budget reasoning;
- proactive in-app resurfacing;
- optional contextual nudges.

Exit: recommendations are measurably more useful than manually browsing the collection.

## Phase 5 — Shared living

Only after core use is established, test:
- grocery/shared lists;
- goals;
- trip funds/purpose funds;
- lightweight plans;
- calendar context;
- location-aware features with explicit consent.

## Phase 6 — Specialized domains

Potential modules/integrations:
- Wayfare travel/place layer;
- richer media integration;
- food/recipe layer;
- gifts/wants;
- games/activities;
- intimate shared-space experiences.

Modules must reuse the shared object/memory model where possible rather than becoming disconnected mini-products.

## Roadmap rule

A requested feature enters the next phase only if it either:

1. strengthens an already validated behavior; or
2. tests a clearly stated new hypothesis.

“Couples might use this” is not sufficient prioritization evidence.
